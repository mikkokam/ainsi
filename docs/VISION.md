You write a deck in markdown. No layout, no positions, no theme authoring — you say what a block is ("this list is a timeline"), never what it looks like. Point the tool at the file and you get one self-contained HTML page: opens in any browser, presents full-screen, prints, exports a PDF, and reflows into a readable document on a phone.

Pages are computed, not authored. Too much on a slide and the solver steps the type down within the range your theme allows, then splits at the natural seam — and if it truly can't fit, it tells you instead of quietly eating a paragraph.

Rebranding is swapping one folder. Every deck you ever made re-renders in the new look, untouched.

When the last mile is visual — and it always is — you open the studio: click a block, change what it is, edit the text, try another theme, watch it land. It's editing your markdown file the whole time. Close the studio and you still just have a .md and an .html, no database, no account, no lock-in.

And an agent can drive all of it, writing the same markdown you would, through the same door.
